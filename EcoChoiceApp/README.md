# EcoChoice - Приложение для выбора экологических продуктов

## Описание
EcoChoice - это Android-приложение, которое помогает пользователям находить и выбирать экологически чистые продукты. Приложение предоставляет информацию об эко-рейтинге товаров и позволяет легко искать нужные продукты.

## Основные функции
- 🌱 **Каталог эко-продуктов** - Список продуктов с оценкой экологичности
- 🔍 **Поиск** - Быстрый поиск по названию и описанию продуктов
- 📊 **Эко-рейтинг** - Визуальная индикация уровня экологичности (0-100%)
- 🎨 **Современный UI** - Material Design с зеленой темой

## Установка и запуск

### Требования
- Android Studio Arctic Fox или новее
- JDK 8 или новее
- Android SDK API 34

### Шаги
1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Запустите на эмуляторе или реальном устройстве

## Сборка APK
```bash
./gradlew assembleDebug
```

APK файл будет создан в: `app/build/outputs/apk/debug/`

## Использование
1. При запуске отображается список эко-продуктов
2. Используйте строку поиска для фильтрации
3. Каждый продукт показывает:
   - Название
   - Описание
   - Изображение
   - Эко-рейтинг в процентах

## Цветовая схема
- 🟢 Зеленый (#4CAF50) - Высокий эко-рейтинг (90%+)
- 🟡 Желтый (#FFC107) - Средний эко-рейтинг (75-89%)
- 🔴 Красный (#F44336) - Низкий эко-рейтинг (<75%)
